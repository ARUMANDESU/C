# Basic types

C has a series of basic type and means of constructing derived types from them.

There is first level of specification that is done entirely with keyword of the language, such as `signed`, `int`, `double`.
The first level is organized according to C internals. On top of that is a second level of specification that comes with through header files, such as `size_t`, `bool`. This second second level is organized by type semantics, specifying what properties of particular type brings to the programmer.
